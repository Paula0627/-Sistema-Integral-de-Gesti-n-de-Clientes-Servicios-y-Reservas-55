# Software FJ

## Descripción
Este proyecto consiste en un sistema integral de gestión de clientes, servicios y reservas para la empresa Software FJ, desarrollado en Python utilizando Programación Orientada a Objetos (POO), sin uso de bases de datos.

El sistema permite:

- Registrar clientes
- Gestionar servicios
- Crear reservas
- Validar datos
- Manejar errores mediante excepciones
- Registrar eventos y errores en archivos logs

## Tecnologías usadas
- Python
- Programación Orientada a Objetos (POO)
- Manejo de archivos
- Excepciones personalizadas

## Características implementadas
- Abstracción
- Herencia
- Polimorfismo
- Encapsulación
- Manejo avanzado de excepciones
- Registro de logs
- Validaciones robustas

## Servicios disponibles
1. Reserva de salas
2. Alquiler de equipos
3. Asesorías especializadas

## Archivos del proyecto

- cliente.py
- excepciones.py
- servicio.py
- reserva.py
- main.py
- logs.txt
